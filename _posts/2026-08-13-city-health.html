📐 标准大纲结构

严格遵循住建部工作手册附件四的9章标准框架。前两章交代背景与方法，中间四章是四个维度的核心诊断， 第7章为主观民意验证，第8章为问题与对策的核心产出，最后第9章为系统性治理建议。 总字数约3-4万字，四个维度章节占比约60%。

  • 第1章 城市体检工作概述：总体要求、体检范围、工作机制、技术路线
  • 第2章 体检指标体系构建：1+N+X体系说明、55项基础指标介绍、特色指标说明
  • 第3章 住房维度指标分析诊断：安全耐久、功能完备、绿色智能三类8项指标分析
  • 第4章 小区(社区)维度分析：设施完善、环境宜居、管理健全三类10项指标分析
  • 第5章 街区维度分析诊断：功能完善、整洁有序、特色活力三类8项指标分析
  • 第6章 城区(城市)维度分析：五大方向27项指标综合评价
  • 第7章 居民抽样问卷调查分析：满意度评价、突出问题、主客观对比
  • 第8章 问题清单与整治建议清单：分级分类问题汇总、对应整治措施
  • 第9章 治理对策与行动建议：系统性治理策略、年度行动建议、长效机制

📚 基础资料准备

资料齐备是AI生成高质量报告的前提。核心是55项指标的原始数据和上年度整改情况， 规划和政策文件作为背景支撑，调查数据用于主客观交叉验证。建议按类别分文件夹整理， 便于AI自动识别和读取。

  • 上年度体检资料：上年报告、问题清单、整改完成情况（计算问题整治率必备）
  • 指标原始数据：住建部55项基础指标各部门报送数据，是报告的核心数据源
  • 规划依据文件：国土空间总体规划、各相关专项规划，作为达标判定参照
  • 居民调查数据：居民满意度问卷原始数据，样本量不低于800份
  • 专项普查成果：第一次自然灾害风险普查、城市危旧房摸底调查等专项数据
  • 统计年鉴年报：各部门官方统计数据，用于交叉验证和补充说明
  • 政策标准文件：国家及省市工作通知、技术标准、相关政策要求

✍️ 写作核心重点

城市体检报告不是简单的数据罗列，而是诊断分析报告。核心要求是"用数据说话、用问题导向、 用对策落地"，每一项指标都要完成"数据呈现→达标判定→问题诊断"的完整闭环， 不能只列数字不分析，也不能只说问题不给对策。

  • 指标计算准确可追溯：每项数据标注来源和计算方法，确保可核查、可复现
  • 达标判定分级清晰：区分底线型（安全红线，一票否决）和提升型（品质优化）
  • 问题诊断有数据支撑：每个问题必须对应具体指标数值，不能凭感觉定性
  • 对策建议对应可落地：整治建议与问题一一对应，明确实施路径和责任方向
  • 纵横对比体现变化：与上年度对比看整改成效，与同类城市对比看发展水平
  • 主客观交叉验证：客观指标数据与居民主观满意度相互印证，发现隐性问题
  • 问题分级分类管理：按严重程度、责任主体分类，便于后续整改落实

🖼️ 配图与图纸要求

城市体检是空间性很强的工作，图纸是重要组成部分。GIS空间分布图体现问题的空间分布特征， 统计图表展示量化对比关系。AI负责生成数据和文字分析，空间图纸需GIS软件配合出图， 但AI可以给出图纸清单和制图要求。

  • 基础底图类：城市区位图、行政区划图、建成区范围图、体检单元划分图
  • 空间分布类：各指标空间分布图（GIS出图）、问题点位分布"问题地图"
  • 统计图表类：各维度达标率柱状图、年度变化折线图、满意度雷达图等
  • 调查分析类：居民满意度分项统计图、不同人群诉求差异对比图
  • 项目布局类：整治建议项目分布示意图、城市更新项目库点位图
  • 典型案例类：重点问题现场照片、整改前后对比图（有条件时配备）
  • 制图规范：统一图例、比例尺、指北针，图号图题格式规范

🎯 最终成果交付

完整的城市体检成果由"文本+图纸+附件"三部分组成。文本是主体报告，图纸是空间表达， 附件是支撑数据和标准化清单。其中问题清单和整治建议清单是核心交付物， 直接对接城市更新项目库，是"先体检后更新"的关键衔接点。

  • 文本部分：城市体检总报告正文（9章，约3-4万字）
  • 图纸部分：相关指标图集（GIS出图，按章节顺序编排）
  • 附件1 指标数据表：55项基础指标完整数据表，含数值、单位、来源
  • 附件2 问题台账：住房、小区、街区三个维度分维度问题明细台账
  • 附件3 问题清单：汇总版问题清单，分级分类（底线型/提升型）
  • 附件4 整治建议清单：对应问题的整治措施，分限时解决/持续推进
  • 附件5 更新项目库：基于体检结果生成的城市更新建议项目清单

⭐ 评审关键要点

评审重点关注"全、准、实"三个字。全覆盖——55项指标不能缺项；数据准——来源权威、计算规范； 对策实——问题找得准、建议可落地。同时要体现年度对比和整改闭环， 验证"体检-整改-再体检"的工作机制是否有效运转。

  • 指标体系完整性：55项基础指标是否全覆盖，特色指标设置是否合理
  • 数据来源权威性：数据是否来自官方渠道，计算方法是否规范统一
  • 问题查找精准度：是否找准真问题，有无遗漏重大安全隐患
  • 整治建议可行性：对策是否可操作，责任主体是否明确，时序安排是否合理
  • 整改成效体现：与上年度对比，问题整改率如何，有无体现持续改进
  • 问卷样本合规性：样本量是否达标（≥800份），抽样分布是否科学
  • 更新衔接到位度："先体检后更新"是否落地，项目库与问题清单是否对应

📊 "1+N+X"四级指标体系（55项基础指标）

住建部2026年统一基础指标共55项，各地可在此基础上增加地方特色指标（X），实际执行通常为60项左右。 其中"1"为四个维度层级，"N"为基础指标，"X"为地方特色体检内容。

🚀 零基础实战：8步生成城市体检报告

面向完全没用过豆包Agent的新手，每一步都有详细操作说明

📌 开始前的准备工作

  • 在电脑上建立项目文件夹，命名如"XX市2026年城市体检"
  • 按标准目录结构建立子文件夹，分类放入各类资料文件
  • 根目录放一个项目说明.txt，写明：城市名称、年度、体检范围、特殊要求
  • 打开豆包桌面版，登录账号，进入办公任务功能
1

创建项目：建立本地文件夹并关联豆包

操作步骤：
  1. 在电脑上建立项目文件夹，命名如"XX市2026年城市体检"
  2. 按以下目录结构放入各类资料文件：
    • 01_规划依据/（总规、专项规划等）
    • 02_指标数据/（各部门数据、统计年鉴等）
    • 03_调查数据/（居民问卷、现场普查表等）
    • 04_政策文件/（工作通知、工作手册等）
    • 05_上年度资料/（上年报告、整改情况等）
    • 项目说明.txt（写明城市、年度、范围、特殊要求）
  3. 打开豆包桌面版，进入"办公任务"功能
  4. 选择"本地电脑文件夹项目"，关联刚才建立的项目文件夹
  5. 豆包自动读取文件夹内所有文件，建立项目认知
  6. 在对话框中粘贴下方启动提示词，确认项目启动
💬 启动提示词（直接复制粘贴）：
# 第1步：项目启动提示词 这是一个城市体检报告编制项目，项目文件夹已关联，请先全面读取文件夹中的所有文件，建立对项目的整体认知。 【项目基本信息】 - 项目名称：XX市2026年城市体检报告 - 编制依据：住建部2026年城市体检工作手册 - 体检范围：XX市建成区 - 报告要求：官方正式语体，约3-4万字，55项基础指标全覆盖 请完成以下工作： 1. 梳理现有资料清单，按子文件夹分类列出你读取到的文件 2. 对照住建部55项基础指标，指出还缺少哪些关键数据 3. 说明你对这个项目的理解和后续工作思路 不用写正文，先做资料盘点和项目理解就好。
💡 新手提示：这一步叫"项目初始化"，就像给新人培训一样，让AI先把所有资料看完， 建立项目认知。不要一上来就让它写报告，那样质量会很差。等它回复后，你再确认理解是否正确，有偏差及时纠正。
2

数据整理：55项指标结构化汇总

任务目标：

让AI把分散在各个文件中的指标数据整理成一张统一的指标统计表，计算各项达标情况。

操作说明：

确认AI对项目理解正确后，发送以下提示词，让它开始数据整理工作。

💬 指标整理提示词：
# 第2步：指标数据整理提示词 请基于文件夹中的各项数据，按照住建部2026年城市体检55项基础指标体系，整理生成完整的指标统计表。 要求： 1. 严格按照四个维度（住房、小区、街区、城区）+ 问题整治的顺序排列 2. 每项指标包含：指标名称、指标值、单位、数据来源、达标判定（达标/未达标/不适用） 3. 住房和小区维度按栋数/个数统计，城区维度按百分比/人均值统计 4. 达标判定参考工作手册中的标准，没有明确标准的标注"参考值" 5. 最后增加一行汇总：达标XX项，未达标XX项，不适用XX项 6. 输出为Markdown表格格式，方便后续复制使用 注意：所有数据必须来自项目文件夹中的资料，没有数据的指标标注"待补充"，绝对不能编造数据。
💡 新手提示：这一步产出的指标表是整个报告的核心数据基础。 生成后你一定要逐项核对数据准确性，发现错误立刻让它修正。 数据错了，后面的分析全都会错。
3

大纲构建：确认报告章节框架

任务目标：

💡 Skill固化：打造你的专属城市体检专家

做完一个项目后，把所有经验提炼成一条完整指令，下次直接调用

❓ 什么是Skill？为什么要做Skill固化？

Skill就是把一整套工作方法、写作要求、质量标准浓缩成一条完整的启动指令。 做完第一个城市体检项目后，你会积累很多经验：哪些地方AI容易写错、什么格式最规范、 哪些提示词效果最好。把这些经验全部整理进一条指令里，下次做新项目时， 只要把这条指令发给豆包，AI就直接按照你的标准流程来做，中间8步的提示词都不用再写了。

🔧 Skill是怎么生成的？（三步提炼法）

第一步：项目做完后复盘 回顾整个项目，把踩过的坑、调整过的要求、效果好的写法都总结出来
第二步：AI自动整理提炼 告诉AI"把本项目的全部工作方法整理成标准Skill"，AI自动分类归纳
第三步：生成Skill.md文件 AI输出完整的skill.md文件保存到项目文件夹，下次项目直接调用

📦 一个完整Skill的6大构成模块

1. 角色身份设定 告诉AI它是谁、擅长什么、专业背景是什么，建立人设
2. 核心工作原则 红线要求：数据不能编、标准不能改、问题不能漏、责任要明确
3. 标准工作流程 从资料盘点到最终交付的完整步骤，每步做什么、产出什么
4. 写作规范要求 语体风格、章节结构、数据表述、问题分级等具体写作标准
5. 输出格式标准 标题层级、表格格式、Word排版、附件清单等交付规范
6. 质量检查节点 哪些环节需要人工确认，避免跑偏，把控整体质量

📝 完整Skill启动指令示范（做完第一个项目后可直接套用）

【角色身份】 你是一位资深城市规划工程师，专门负责城市体检报告编制工作，精通住建部《2026年城市体检工作手册》全部要求。 写作风格：正式、严谨、数据驱动、符合政府公文规范，不用空话套话。 【核心工作原则】 1. 数据真实原则：所有指标数据必须来自项目文件夹中的资料，严禁编造数据，缺失的标注"待补充" 2. 标准统一原则：严格按照55项基础指标体系工作，不随意增减指标 3. 问题导向原则：每个分析结论必须对应具体问题，每个问题必须有数据支撑 4. 分级分类原则：问题分底线型/提升型两类，整治分限时解决/持续推进两类 5. 人工确认原则：数据整理、大纲构建、问题清单三个节点，必须等用户确认后再继续 【标准工作流程】 第一步：资料盘点 → 读取文件夹全部资料，输出分类清单和数据缺漏清单 第二步：指标整理 → 生成55项指标统计表，含数值、单位、来源、达标判定 第三步：大纲构建 → 按9章标准框架生成三级目录和各章节篇幅分配 第四步：分章撰写 → 按住房→小区→街区→城区→问卷→对策的顺序逐章撰写 第五步：清单生成 → 汇总问题清单和整治建议清单，按分级分类标准整理 第六步：统稿质检 → 全文术语统一、数据前后核对、逻辑衔接、格式规范 第七步：成果交付 → 生成Word正文 + 7个标准附件表格 【写作规范要求】 - 每章结构：总体概况 → 分项分析 → 问题总结，三段式 - 每个指标都要有"数据+分析+结论"三要素，不能只列数字 - 问题诊断要挖到原因层面，不能只描述现象 - 整治建议要具体可落地，明确责任单位方向，不能空泛 - 全文语体统一为正式的政府工作报告风格 【输出格式标准】 - 标题层级：第X章（一级）、X.X（二级）、X.X.X（三级） - 正文：宋体小四，1.5倍行距，首行缩进2字符 - 表格：三线表格式，表题在上方，统一编号（表3-1、表5-2...） - Word交付：封面+目录+9章正文+7个附件，附件前分页 - 关键节点完成后主动询问："以上是否确认？确认后继续下一步" 【使用说明】 收到这条指令后，等待用户关联项目文件夹并说明基本信息，然后按上述流程自动推进。 每完成一个关键节点暂停，等待用户确认后再进入下一步。

💡 Skill生成与调用方法：

  1. 项目收尾时生成：做完第一个城市体检项目后，告诉AI"把本次项目的全部工作方法、写作要求、质量标准整理成一个完整的Skill，输出为skill.md格式文件保存到项目文件夹"
  2. 形成标准Skill文件：AI会自动生成 城市体检报告编制Skill.md，包含角色设定、工作原则、流程步骤、输出规范等全部内容
  3. 新项目直接调用：下次做新项目时，把这个Skill.md文件放入项目根目录，或者启动时直接指定调用该Skill文件
  4. 自动按流程推进：AI读取Skill后自动按照标准化流程执行，不用你再一步步想提示词，每到关键节点会自动暂停等你确认
  5. 持续迭代优化：每做完一个项目，让AI把新积累的经验补充更新到Skill文件里，版本号递增，越用越成熟

最终形成的Skill文件是团队可共享的标准化资产，新人拿到文件就能快速上手， 保证不同项目、不同人员的输出质量稳定一致。

AI 发展简史：从规则到智能体

了解 AI 是怎么一步步发展到今天的 AI Agent，你会更清楚它的能力和边界

AI 不是一夜之间出现的。它经历了 70 多年的演进，大致可以分为五个阶段：

1950s - 1970s

规则系统时代

人类给 AI 写死规则："如果用户说 X，你就回答 Y"。代表：ELIZA（1966 年的心理咨询机器人）。它能模仿人类对话，但完全不理解内容，只是模式匹配。

1980s - 1990s

专家系统时代

把领域专家的知识编码成规则库。比如医疗诊断系统输入症状、输出疾病。问题是规则越加越多、维护成本爆炸，遇到没见过的病例就傻眼。

2000s - 2011

机器学习时代

不再手写规则，而是给 AI 大量数据，让它自己找规律。垃圾邮件过滤、推荐算法都是这个阶段的产物。但需要人工提取"特征"，能力有限。

2012 - 2020

深度学习时代

2012 年 AlexNet 在图像识别中一鸣惊人，深度神经网络开始爆发。AI 不再需要人工提取特征，能自己从原始数据中学习。2017 年 Transformer 架构问世，为后来的大语言模型奠定了基础。

2020 - 至今

大模型与 Agent 时代

2020 年 GPT-3 展示了"涌现能力"——参数量到一定程度后，AI 突然能做很多没专门训练过的事。2022 年 ChatGPT 让所有人都能用上 AI。2023 年起，AI 不只是"聊天"，而是进化为 Agent——能使用工具、记住上下文、自主完成多步骤任务的智能体。

关键转折点

2017 年，Google 发表论文《Attention Is All You Need》，提出了 Transformer 架构。这是现代所有大语言模型（GPT、BERT、文心一言、豆包等）的技术基石。它的核心创新是"注意力机制"——让 AI 在处理一句话时，能自动关注最相关的词。

大模型基本原理：AI 是怎么"思考"的

不需要数学知识，用大白话理解大语言模型的工作原理

1. 大语言模型在做什么？

用一句话概括：大语言模型就是在做"文字接龙"。

你给它一段文字（叫"上下文"），它预测接下来最可能出现的字或词是什么。然后把这个预测结果加到上下文里，再预测下一个——如此循环，就生成了一整段回答。

举例：如果你给模型看到"今天天气很"，它会预测下一个字大概率是"好"或"热"或"冷"。它不是"理解"天气，而是从训练数据中学到了"天气很"后面通常接这些字。

2. 训练：AI 是怎么学会的

大模型的训练分三个阶段：

阶段做了什么通俗比喻
预训练让模型阅读海量互联网文本，学习语言的统计规律像小孩读了整个图书馆，认识了字词怎么搭配，但还不会回答问题
指令微调用"问题-回答"格式的人工标注数据训练，让模型学会按指令行事像上了礼仪课，知道别人问问题时该怎么回答
人类反馈强化学习（RLHF）让人类给模型的回答打分，用分数信号优化模型，让它输出更有用、更安全的内容像老师批改作业，告诉它哪些回答好、哪些不好，它逐步改进

3. 关键概念

概念解释
Token（词元）AI 处理文字的最小单位。一个汉字大约 1-2 个 token，一个英文单词大约 1 个 token。你和 AI 对话时，文字会被切成 token 再处理。
上下文窗口AI 一次能"看到"的最大文字量。比如 128K 窗口大约能容纳 10 万字。超出窗口的早期对话会被"遗忘"。
温度（Temperature）控制 AI 回答的"随机性"。温度低 = 更确定、更保守；温度高 = 更有创意、更多样。一般对话用 0.7 左右。
幻觉（Hallucination）AI 一本正经地胡说八道。因为它是基于概率生成文字，有时候会生成看起来合理但实际错误的内容。这是使用 AI 时最需要注意的风险。
为什么 AI 会"一本正经地胡说八道"

大模型的本质是概率预测，不是知识检索。它不知道"事实是什么"，只知道"通常接下来会说什么"。当训练数据中没有相关内容时，它会根据语言规律"编"出一个看起来合理的答案。这就是为什么重要信息一定要核实。

4. 从大模型到 AI Agent：多了什么

大语言模型本身只是一个"文字生成器"——你输入文字，它输出文字。但 AI Agent 在此基础上增加了：

能力大模型AI Agent
工具使用不能调用外部工具能搜索网页、读写文件、运行代码、创建文档
记忆只记住当前对话能跨对话记住项目上下文和个人偏好
规划给一个问题答一个能把复杂目标拆解为多个步骤，逐步执行
执行输出文字到聊天框能直接操作文件系统、部署网页、提交代码

一句话总结：大模型是 AI 的"大脑"，Agent 是给大脑装上了"手"和"记忆"。大模型能想，Agent 能做。

什么是 AI Agent

正式定义 AI Agent，以及它和普通 AI 对话的区别

AI Agent（人工智能智能体）是一种能够自主感知环境、理解目标、拆解任务、调用工具、执行操作并交付成果的智能系统。

用一个生活化的比喻来理解：

普通 AI 对话：你问厨师"红烧肉怎么做"，厨师告诉你步骤，你自己去做。

AI Agent：你跟厨师说"帮我做一份红烧肉"，厨师自己走进厨房、找食材、切肉、调味、出锅，把菜端到你面前。

具体到你的学习场景：

维度普通 AI 对话AI Agent
你说"帮我整理笔记"它输出整理后的文字，你手动复制保存它自动整理、保存为文件，下次还能读取
你说"帮我做个背单词程序"它给你代码片段，你自己复制到编辑器运行它自己写代码、运行、调试、部署成网页
你说"帮我查资料"它根据记忆回答，可能过时或编造它能实际搜索网页、读取文件，引用真实来源

初识 AI Agent

从大模型到智能体，第一次上手使用

20 分钟 入门
是什么

AI Agent 是在 大语言模型 基础上，增加了工具调用、记忆、规划、执行能力的智能系统。大模型是"大脑"，Agent 给大脑装上了"手"和"记忆"。

你现在使用的 WorkBuddy 就是一个 AI Agent 平台——它不只是聊天，能读写文件、运行代码、创建项目。豆包则是偏日常办公的 AI 助手，擅长语音速记、文档处理、翻译。

有什么用

普通 AI 对话只能"回答问题"，AI Agent 能"完成任务"。区别在于：

场景普通 AI 对话AI Agent
整理笔记输出文字，你手动保存自动整理 + 保存为文件
写代码给你代码片段写完直接运行、调试、部署
查资料凭记忆回答，可能过时实际搜索，引用真实来源
怎么用
  1. 1

    打开 WorkBuddy

    登录后你会看到一个对话界面。这里就是你与 AI Agent 交互的地方——直接用自然语言描述你想做什么。

  2. 2

    理解"项目模式"

    WorkBuddy 的工作方式是"项目"——每个项目是一个独立的工作区，里面有文件、有对话记忆。你在项目里让 AI 做的事，它都记着。这比普通聊天强在成果可以沉淀。

  3. 3

    学会提需求

    跟 AI Agent 交流就像跟一个聪明但不了解你的新同事说话——说清楚背景、目标、要求。比如不要只说"帮我写个计划"，而要说"我是大一新生，需要在 120 天内备考英语四级，每天可用 1.5 小时，帮我制定备考计划"。

动手实践

实践任务：在 WorkBuddy 中完成你的第一次 Agent 对话

打开 WorkBuddy，新建一个对话，把下面的提示词复制进去并发送：

你好！我是大学新生，第一次使用 AI Agent。请你：
1. 用 3 句话介绍一下你自己——你能做什么、不能做什么
2. 帮我写一段 100 字左右的自我介绍模板，我填空即可使用
3. 把这段自我介绍保存为一个叫"自我介绍.txt"的文件

完成后检查：

  • AI 是否介绍了自己的能力和局限？
  • 是否生成了自我介绍模板？
  • 是否创建了文件？（检查项目文件列表）

如果三件事都做到了，恭喜——你刚刚体验了 AI Agent 与普通聊天的区别：它不只是说话，它还做了事。

拓展

学会基本的 Agent 交互后，你可以尝试：

  • 用豆包的语音输入功能，口述一段课堂内容，让 AI 整理
  • 在 WorkBuddy 中创建不同主题的项目（如"课堂笔记""课程作业""学习计划"），分类管理你的任务
  • 尝试让 AI Agent 一次完成多个关联任务，比如"查一下什么是费曼学习法，然后帮我整理成笔记，再生成 3 道自测题"

提示词的艺术

学会写好 Prompt，让 AI 真正听懂你

30 分钟 入门
是什么

Prompt（提示词）就是你给 AI 的输入指令。它可以是简单的一句话（"帮我翻译这段话"），也可以是一段详细的角色设定+任务描述+格式要求。

Prompt 之于 AI Agent，就像需求文档之于程序员——你说得越清楚，产出质量越高。

有什么用

同样一个 AI，不同的 Prompt 会导致天差地别的结果。看这个对比：

差的 Prompt

帮我讲讲高等数学

→ AI 可能给你一段泛泛的百科介绍，没有重点，不知道你想了解哪个方面

好的 Prompt

我是大学新生，正在学习《高等数学》中的"极限"这一章。请帮我：
1. 用通俗语言解释"极限的ε-δ定义"
2. 列出求极限的常用方法及其适用场景
3. 举一个实际例题演示如何用洛必达法则求极限
4. 生成 3 道选择题帮我自测
输出格式：分点列出，每点不超过 3 行

→ AI 给你结构化、有案例、有自测的精准回答

怎么用

Prompt 写作框架：ROCF 法

记住四个字母：R-O-C-F（角色-目标-约束-格式）

字母含义说明示例
RRole 角色告诉 AI 它扮演什么角色"你是一位经验丰富的大学英语老师"
OObjective 目标明确你想达成什么"帮我制定四级备考计划"
CConstraint 约束给出限制条件和背景"我每天只有 1.5 小时，基础中等，距离考试 120 天"
FFormat 格式指定输出格式"按周排列，每周列出具体任务，用表格呈现"

五个进阶技巧

  1. 1

    给上下文

    AI 不知道你是谁。告诉它你的身份、水平、需求——"我是大一新生""我英语基础一般""我需要用于期末复习"。

  2. 2

    给例子

    如果你想要特定格式的输出，给一个例子比描述一百字管用。"像这样：词汇 | 音标 | 释义 | 例句"。

  3. 3

    分步骤

    复杂任务拆成编号步骤："1. 先... 2. 再... 3. 最后..."。AI 会按步骤执行，不容易跑偏。

  4. 4

    要它解释推理过程

    加一句"请说明你的分析过程"或"请标注信息来源"。这让 AI 更严谨，也方便你核实。

  5. 5

    迭代修正

    第一次结果不满意很正常。直接说"第二部分太长了，精简到 3 行""换一种更口语的风格"——AI 会在上一轮基础上调整。

动手实践

实践任务：用 ROCF 框架写 3 个 Prompt 并在 WorkBuddy 中测试

在 WorkBuddy 中依次发送以下 3 个 Prompt，观察结果差异：

练习 1：翻译 + 解释

你是一位熟悉教育领域的翻译专家（R）。请把以下英文段落翻译成中文，并对其中的专业术语做简要解释（O）。要求翻译准确、术语解释不超过 2 句话，用"术语：解释"的格式列出（C/F）。

英文段落：Active recall is a learning method that involves actively stimulating memory during the learning process, as opposed to passive review like re-reading. Studies show it leads to stronger long-term retention compared to passive studying.

练习 2：知识整理

你是一位大学辅导老师（R）。请帮我把以下零散的课堂笔记整理成结构化复习资料（O）。要求：按知识点分组、标注重点、每个知识点配一个记忆口诀，最后生成 3 道自测题（C/F）。

课堂笔记：[粘贴你任意一节课的笔记，或者用这段测试内容："微积分基本定理连接了微分和积分。牛顿和莱布尼茨各自独立发现。核心思想是积分可以用原函数在端点的值来算。F(b)-F(a)就是定积分的值。F是f的原函数，也就是F'=f。这个定理大大简化了定积分计算，不用再求极限了。要注意原函数不唯一，差一个常数。计算时经常用变上限积分。"]

练习 3：计划制定

你是一位专业的时间管理顾问（R）。请帮我制定一份本周学习计划（O）。我的情况：大一新生，这周有高等数学和大学英语两门课要复习，还需要背 200 个英语单词，每天晚上 7-9 点可用，周末多 2 小时（C）。请用表格形式输出，按天列出任务，标注预计耗时（F）。

完成后思考：对比三个 Prompt 的结果，哪个最接近你想要的？如果不够好，试着用"迭代修正"技巧再追发一条调整指令。

拓展

Prompt 写作是一个可以持续精进的技能：

  • 少样本提示（Few-shot）：给 AI 2-3 个输入输出示例，让它模仿格式。比如给它 3 个"单词+释义"的例子，然后让它按同样格式处理新单词。
  • 思维链（Chain of Thought）：在 Prompt 中加"请一步步思考"，AI 会展示推理过程，答案更准确。适合数学题、逻辑推理。
  • 角色链：让 AI 先扮演"出题者"出题，再扮演"答题者"答题，最后扮演"阅卷者"批改——一轮对话完成闭环练习。
  • 把常用的 Prompt 模板存到手机备忘录里，随用随取（本课程附录有速查卡）。

智能笔记术

用 AI 整理课堂笔记，建立知识体系

35 分钟 基础
是什么

智能笔记术是指用 AI Agent 把零散的课堂记录（手写笔记、PPT 照片、语音记录）转化为结构化、可检索、可复习的知识文档。

核心流程：速记 → AI 整理 → 文件沉淀 → 期末汇总。

有什么用

大学课程信息量大，传统笔记方式有三个痛点：

痛点AI 怎么解决
课堂记不全，课后看不懂自己的笔记用豆包语音速记课后复述，AI 自动转文字并补全逻辑
笔记散落在各处，期末找不到用 WorkBuddy 统一保存为文件，按课程/章节分类
复习时不知道重点在哪让 AI 从笔记中提取考点、生成自测题
怎么用
  1. 1

    课后速记（用豆包）

    下课后立刻打开豆包，用语音输入复述课堂内容。不用管格式，想到什么说什么，越详细越好。豆包自动转文字。

  2. 2

    AI 结构化整理（用 WorkBuddy）

    把豆包的速记文本发给 WorkBuddy，用以下 Prompt 整理：

    以下是我今天的课堂速记（语音转文字），请帮我整理成结构化笔记：
    1. 按"知识点 - 定义 - 要点 - 案例"格式组织
    2. 标注重点（★）和可能考点（▲）
    3. 专业术语用加粗标注
    4. 如果有明显遗漏或逻辑断裂的地方，用 [?] 标注提醒我补充
    5. 保存为 Markdown 文件，文件名格式：日期-课程名-章节主题

    课堂速记：[粘贴速记内容]

  3. 3

    期末汇总复习

    到期末，所有笔记已经按文件保存在 WorkBuddy 项目里。直接说：

    读取这个项目里所有"高等数学"相关的笔记文件，帮我：
    1. 生成一份按章节组织的期末复习大纲
    2. 标注高频考点（在多个笔记中都出现的知识点）
    3. 生成 20 道自测题（10 道选择 + 10 道简答），附带答案
    4. 输出为一份完整的复习文档

动手实践

实践任务：用 AI 整理一段课堂笔记

在 WorkBuddy 中发送以下 Prompt（使用提供的测试内容，或替换成你自己的笔记）：

以下是我上《高等数学》课的课堂速记，请帮我整理成结构化笔记并保存为文件。

速记内容：
"今天讲了导数的应用。主要讲了几个方面。第一是函数的单调性，导数大于零就是增函数，小于零就是减函数。第二是极值，极值点处导数为零或者不存在，但导数为零不一定是极值点，还要看左右导数是否变号。老师强调了一阶导数判别法。第三是最值问题，闭区间上连续函数一定有最大值和最小值，在端点或极值点取到。然后讲了二阶导数，二阶导数可以判断凹凸性。大于零是凹函数，小于零是凸函数。拐点就是凹凸性改变的点。最后讲了洛必达法则，用来求0/0型或无穷比无穷型的极限，对分子分母分别求导再求极限。老师提醒洛必达法则不是万能的，有时候求导后更复杂了。"

要求：按"知识点-定义-要点-案例"格式组织，标注重点和考点，保存为"高等数学-导数的应用.md"

完成后检查：

  • 笔记是否按知识点分组？
  • 是否标注了重点和考点？
  • 是否区分了"极值"和"最值"的概念？
  • 是否成功保存为文件？
拓展

掌握笔记整理后，你还可以：

  • 知识卡片：让 AI 从笔记中抽取每个知识点，生成"正面问题/背面答案"的闪卡格式，导入 Anki 等记忆软件
  • 思维导图：让 AI 用 Markdown 缩进格式生成知识结构，导入 XMind 等工具一键生成思维导图
  • 跨课程关联：让 AI 找出不同课程笔记之间的关联，比如《高等数学》中的微积分与《大学物理》中运动学计算的对应关系
  • 案例库：每遇到一个重要例题或案例就让 AI 整理成标准格式（题目-解题思路-分析-举一反三），积累个人习题库
资源链接
  • 🃏 Anki（apps.ankiweb.net）：免费的开源记忆卡片软件，支持 AI 生成的闪卡导入
  • 🧠 XMind（xmind.cn）：思维导图工具，支持导入 Markdown 格式
  • 📝 Obsidian（obsidian.md）：基于 Markdown 的知识管理软件，适合长期积累笔记

AI 检索术

比搜索引擎更聪明的查资料方式

35 分钟 基础
是什么

AI 检索术是用 AI Agent 进行多轮、多维度、结构化的信息检索。与传统搜索引擎的区别：不是给你一堆链接让你自己翻，而是帮你搜、帮你读、帮你整理。

有什么用
传统搜索的问题AI 检索怎么解决
关键词匹配，搜到很多无关内容用自然语言描述需求，AI 理解意图后精准检索
需要自己打开多个网页阅读筛选AI 自动读取多个来源，提取关键信息汇总
搜到的信息零散，需要自己组织AI 按你要求的格式整理成结构化文档
查完一个方向不知道下一步查什么AI 能根据初步结果建议下一步检索方向
怎么用

AI 检索的关键是分轮次、逐步深入，而不是一句话指望 AI 给你一切。

  1. 1

    第一轮：确定方向

    我需要了解"人工智能在教育领域的应用现状"。请帮我：
    1. 梳理这个主题下有哪些主要的应用方向
    2. 每个方向的核心技术和代表性产品有哪些
    3. 推荐我优先深入了解的 2-3 个方向及理由

  2. 2

    第二轮：深入检索

    根据第一轮的建议，选择一个方向深入：

    我选择深入了解"AI 辅助个性化学习"。请帮我检索：
    1. 目前主流的个性化学习推荐算法（协同过滤、知识图谱等）
    2. 每种方法的原理、优缺点、适用场景
    3. 在实际教育产品中的应用案例
    4. 相关的权威研究论文或报告
    请标注信息的可能来源，方便我核实。

  3. 3

    第三轮：交叉验证 + 整理

    基于以上检索结果，请帮我：
    1. 整理成一份结构化的资料汇编文档
    2. 标注哪些信息是确定的（有明确法规/标准支撑）、哪些是存疑的（需要进一步核实）
    3. 列出我还应该查阅的权威资料来源（如具体的标准号、论文数据库关键词）
    4. 保存为文件

重要：AI 检索结果必须核实

AI 可能产生幻觉——编造不存在的文献编号、虚构研究结论、捏造数据。对于学术引用、数据来源、事实结论等关键信息，务必到权威平台核实：

  • 学术文献：中国知网（cnki.net）、Google Scholar
  • 权威数据：国家统计局（stats.gov.cn）、各部委官方网站
  • 百科知识：维基百科、百度百科（仅作参考，需交叉验证）
动手实践

实践任务：完成一次三轮 AI 检索

在 WorkBuddy 中，选择一个你正在学习的专业话题（或使用下面的建议话题），按三轮检索法操作：

建议话题（任选一个）：

  • "大学生时间管理与效率提升的科学方法"
  • "人工智能在心理健康辅导中的应用"
  • "在线教育平台的技术架构与用户体验设计"

第一轮：发送上面的"第一轮"Prompt（替换主题）
第二轮：根据 AI 回复中推荐的方向，选择一个深入检索
第三轮：让 AI 整理成文档并保存

完成后检查：文档是否结构清晰？是否标注了需要核实的信息？是否列出了权威资料来源？

拓展
  • 外语文献阅读：把英文论文/标准发给 AI，让它翻译并提炼要点。比纯机翻好，因为 AI 能理解上下文
  • 对比分析：让 AI 对比两部法律对同一问题的不同规定，或对比两种检测技术的优劣
  • 案例追踪：给 AI 一个案例的基本信息，让它帮你检索相关法律条文、类似案例、判决结果
  • 数据提取：把包含数据的网页或文档发给 AI，让它提取关键数据并整理成表格
资源链接
  • 📚 中国知网：cnki.net —— 学术文献检索（学校一般有账号）
  • 🌐 万方数据：wanfangdata.com.cn —— 另一个学术数据库
  • 🔎 Google Scholar：scholar.google.com —— 国际学术文献检索
  • 📊 国家统计局：stats.gov.cn —— 权威数据查询

AI 规划师

让 AI 帮你制定学习计划和备考策略

40 分钟 进阶
是什么

AI 规划师是指用 AI Agent 把一个大目标（如"过英语四级""期末复习三门课"）拆解为可执行、可追踪、可调整的分步计划。核心能力是目标拆解 + 时间排期 + 动态调整。

有什么用

大多数学生的学习计划失败，不是不够努力，而是：

  • 计划太笼统："每天背单词"——背多少？复习哪些？不知道
  • 没考虑实际约束：排了 4 小时学习，但没算上课、训练、吃饭的时间
  • 不会动态调整：某天没完成就放弃了，不会根据进度调整后续计划

AI Agent 能根据你的具体水平、可用时间、截止日期生成个性化计划，而且每次执行后可以根据反馈调整。

怎么用

案例：120 天英语四级备考计划

  1. 1

    第一步：能力诊断 + 计划生成

    你是专业英语教学顾问（R）。请帮我制定 120 天的四级备考计划（O）。

    我的情况（C）：
    - 大学新生，英语基础较好，高考英语 130 分左右
    - 词汇量约 3500，听力较弱
    - 每天可用 1.5 小时（工作日），周末 3 小时
    - 有早自习和晚自习，时间较固定

    要求（F）：
    1. 分"基础积累期""专项突破期""模拟冲刺期"三个阶段
    2. 每阶段有目标和每日任务
    3. 词汇/听力/阅读/写作/翻译五项均衡
    4. 每两周设一次自测节点
    5. 用表格输出第一周的详细计划

  2. 2

    第二步：生成每日词汇表

    基于上面的计划，帮我生成第一周的每日词汇表：
    1. 每天新学 40 个单词，按"高频→中频→低频"排序
    2. 结合艾宾浩斯遗忘曲线安排复习
    3. 每个词条包含：单词 | 音标 | 词性 | 释义 | 例句
    4. 适当加入大学学术英语高频词汇
    5. 输出为表格，方便打印

  3. 3

    第三步：模拟测试后动态调整

    两周后做一次模拟测试，把成绩发给 AI：

    我做了四级模拟测试：听力 120/248.5，阅读 160/248.5，写作翻译 130/248.5，总分 410（差 15 分过线）。听力新闻题错最多，翻译遇到专业词汇不会。距离考试还有 60 天。请根据弱项调整接下来的计划，重点突破听力和翻译。

计划的正确用法

AI 给你的计划是起点不是终点。执行一周后回来告诉 AI："这周词汇任务完成了，但听力没时间做"——让它调整。计划的强度在于持续反馈和调整，而不是一次生成就照做。

动手实践

实践任务：制定你自己的学习计划

在 WorkBuddy 中，用 ROCF 框架写一个 Prompt，为你的一个真实学习目标制定计划。参考以下模板填入你的信息：

你是专业的学习规划顾问。请帮我制定一份 [天数] 天的 [目标名称] 备考/复习计划。

我的情况：
- 身份：[大一/大二学生]
- 当前水平：[描述你的基础]
- 每天可用时间：[具体小时数]
- 时间限制：[如课表、训练等固定安排]
- 距离截止还有：[天数]

要求：
1. 分阶段，每阶段有明确目标
2. 每日任务具体可执行
3. 设自测节点
4. 用表格输出第一周计划
5. 保存计划为文件

目标建议（任选）：英语四级备考、期末某门课复习、计算机等级考试、下学期课程预习

拓展
  • 多目标协调：同时备考四级 + 准备期末 + 参加社团活动，让 AI 帮你在一个时间表里协调多个目标
  • 习惯养成：让 AI 设计一个 21 天习惯养成计划（如每天背 30 个单词），包含激励机制
  • 健身计划：如"3000 米跑从 20 分钟提升到 15 分钟"，让 AI 制定 8 周训练方案
  • 项目时间线：做课程作业或学年论文时，让 AI 帮你倒排时间线，避免最后赶工
资源链接
  • 📅 艾宾浩斯遗忘曲线原理：搜索"艾宾浩斯记忆法"了解科学复习间隔
  • 📊 番茄工作法：25 分钟专注 + 5 分钟休息的时间管理方法
  • 🎯 SMART 目标法则：具体/可衡量/可达成/相关/有时限——写目标时参考

AI 编程实战

零基础用 AI 开发一个背单词网页应用

60 分钟 挑战
是什么

AI 编程是指你用自然语言描述需求，AI Agent 帮你写代码、运行、调试、部署。你不需要学编程语法——你的核心技能是描述清楚你想要什么。

这是 AI Agent 最强大的能力之一。WorkBuddy 可以在一个项目里管理所有代码文件、自动写代码、运行测试、修复 bug、部署网页。

有什么用

你可能会想"我又不是计算机专业的，为什么要学编程？"

因为在 AI 时代，编程不再是"写代码"，而是把想法变成产品的能力：

  • 市面上的背单词 App 不能导入你的专业词汇？自己做一个
  • 想把法律条文整理成可搜索的数据库？自己做一个
  • 想可视化你的学习进度？自己做一个
  • 这些成果还能放到 GitHub 上，成为你的数字作品集
怎么用

以开发背单词网页应用为例，完整流程如下：

  1. 1

    需求描述（最重要的一步）

    越详细越好。把你想要的功能一个个列出来：

    我想开发一个网页版背单词程序，用于备考英语四级。需求如下：

    核心功能：
    1. 单词卡片：正面显示英文，点击翻转显示中文释义、音标、例句
    2. 学习模式：每天新学 40 个 + 复习旧词，按艾宾浩斯曲线安排
    3. 测试模式：中文选英文（四选一），记录正确率
    4. 进度统计：已学单词数、掌握程度、连续学习天数
    5. 易错词本：自动收录答错的单词
    6. 词库导入：支持粘贴自定义词汇

    技术要求：
    - 纯前端实现（HTML+CSS+JavaScript），不需要后端
    - 数据用 localStorage 存储，刷新不丢失
    - 界面简洁现代，手机电脑都能用
    - 深色主题

  2. 2

    AI 生成代码

    WorkBuddy 会自动创建项目文件。典型结构：

    项目结构Files
    vocab-app/
├── index.html        <!-- 主页面 -->
├── style.css         <!-- 样式 -->
├── app.js            <!-- 核心逻辑 -->
└── vocabulary.js     <!-- 词库数据 -->

    AI 会逐个文件生成代码。你不需要理解每一行，但建议浏览一遍，了解大致结构。

  3. 3

    测试与调试

    代码生成后 WorkBuddy 会自动预览。实际操作一遍，发现问题就告诉 AI：

    测试发现以下问题，请修复：
    1. 卡片翻转在手机上卡顿
    2. 导入词汇时格式错误会崩溃，需要加格式校验
    3. 统计页面图表没显示

  4. 4

    迭代优化

    请添加以下功能：
    1. 单词发音（用 Web Speech API）
    2. 深色/浅色主题切换
    3. 导出学习数据为 CSV

  5. 5

    部署上线

    功能完善后，可以让 WorkBuddy 部署到云端生成网址，手机浏览器打开就能用。

动手实践

实践任务：在 WorkBuddy 中开发你的第一个网页应用

这是本课程最重要的实践。在 WorkBuddy 中新建一个项目，发送以下 Prompt：

请帮我开发一个网页版背单词程序。功能需求：
1. 单词卡片展示：正面英文单词，点击翻转显示中文释义和例句
2. 四选一测试模式：显示中文，选对应的英文
3. 答错的词自动加入"易错词本"
4. 用 localStorage 存储学习进度
5. 深色主题，手机电脑通用
6. 内置 20 个四级高频词作为初始词库

请生成完整代码并预览效果。如果有问题请自动修复。

完成后尝试：

  • 在预览中实际操作：翻卡片、做测试、查看易错词
  • 发现 bug 就直接告诉 AI 修复
  • 让 AI 添加一个新功能（如发音、统计图表）
不要怕出错

第一次做出来的东西很可能不完美——按钮位置不对、动画卡顿、功能缺失。这很正常。AI 编程的核心不是一次做对，而是快速迭代。发现问题 → 告诉 AI → 修复 → 再测试，几轮下来就会越来越好。

拓展

学会用 AI 开发网页应用后，你还可以尝试：

  • 课程知识查询工具：输入关键词搜索你整理的各科笔记，快速定位知识点
  • 实验数据计算器：输入实验数据自动计算结果、生成图表、输出报告
  • 学习打卡看板：可视化你的学习进度，连续打卡天数、完成率图表
  • 错题本小程序：按科目/难度/知识点筛选错题，支持随机抽题复习
  • 倒计时面板：显示四级考试、期末考试等关键日期的倒计时

所有这些项目都可以用同样的流程：描述需求 → AI 写代码 → 测试调试 → 迭代优化 → 部署上线。

7

GitHub 成果管理

把学习成果提交到 GitHub，建立数字作品集

40 分钟 进阶
是什么

GitHub 是全球最大的代码托管平台。简单说就是一个专门存代码和项目文件的网盘，但它比普通网盘多了版本管理（每次修改都留记录，随时回退）和展示功能（别人可以看你的项目）。

Git 是 GitHub 背后的版本管理工具，安装在本地电脑上，用来追踪文件变化。

有什么用

作品集

你做的程序、整理的资料、写的工具——都展示在主页上，是最直观的能力证明

版本管理

每次修改留记录，改坏了随时回退，告别"最终版v3真的最终版"

个人品牌

考研复试、求职面试时，一个有内容的 GitHub 主页是强加分项

协作能力

团队作业多人协作，学会 Git 是信息化时代的基本素养

怎么用

第一步：注册 GitHub 账号

  1. 1

    打开 github.com，点击"Sign up"。用学校邮箱注册，后续可申请学生包（免费域名等福利）。

第二步：安装 Git

  1. 1

    Windows 下载 Git for Windows，一路 Next 安装。安装后右键能看到"Git Bash Here"。

  2. 2

    打开 Git Bash，配置个人信息：

    全局配置Bash
    git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

第三步：上传项目（三行命令）

在 GitHub 上创建一个仓库后，在本地项目文件夹打开 Git Bash：

上传三步曲Bash
git add .
git commit -m "feat: 我的第一个背单词应用"
git push origin main

就这三行。以后每次修改代码，重复这三行即可推送更新。

第四步：写好 README

README 是别人打开你项目时看到的第一页。模板：

README.md 模板Markdown
# 背单词应用

> 英语四级备考工具，支持艾宾浩斯复习算法

## 功能
- 单词卡片翻转学习
- 四选一测试模式
- 易错词自动收录
- 学习进度统计

## 使用方法
1. 下载项目文件
2. 浏览器打开 index.html
3. 开始学习

## 技术栈
HTML5 + CSS3 + JavaScript + localStorage
让 WorkBuddy 帮你操作 Git

如果你觉得命令行太难，可以直接在 WorkBuddy 里说：

帮我把当前项目的文件用 Git 提交并推送到 GitHub。提交信息写"feat: 完成背单词应用 v1.0"。如果还没有 Git 仓库请先初始化。

WorkBuddy 会自动执行 Git 命令完成上传。

动手实践

实践任务：注册 GitHub 并上传你的第一个项目

  1. 注册 GitHub 账号（用学校邮箱）
  2. 创建一个名为 vocab-app 的仓库（Public，勾选 Add README）
  3. 把第六课开发的背单词程序文件上传到这个仓库
  4. 编写 README.md 描述你的项目
  5. 在仓库页面确认文件都上传成功

成功标志：你可以在浏览器中通过 github.com/你的用户名/vocab-app 访问到你的项目，看到代码和 README。
